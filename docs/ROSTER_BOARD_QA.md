# Roster Board QA

Payroll → Scheduling → **Roster Board** (admin / `ta.settings`).

## Checklist

1. Open Roster Board for current week — 7-day grid (desktop) or day chips (mobile).
2. Add worker to Monday Morning Rinse (+ on shift cell) — Monday worker count updates in summary.
3. Weekly hours and worker drawer reflect the new shift.
4. Estimated cost and funding forecast card update without refresh.
5. Change start/end in edit drawer — hours and cost update on card and summary.
6. Assign worker near OT threshold — OT chip on card and suggestion panel.
7. Remove worker — totals decrease immediately.
8. **Save draft** — persists; partner roster unchanged.
9. Partner roster link — published only, no draft rows.
10. **Publish week** — partner roster shows published schedule.
11. Revoke roster link — partner page empty/denied.
12. Mobile — day chips, sticky summary, edit drawer usable.

## Actions on board

- Save draft / Publish week / Clear draft / Copy prev week / Copy day
- Generate draft roster
- Per card: edit, duplicate, remove, absent, replace
- Suggestions: fill gap, edit conflict
