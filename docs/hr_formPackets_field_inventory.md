# HR / workforce form packets — field inventory and system mapping

This document inventories **`Archive 2.zip`** (extracted under `docs/form_packets_staging/Archive_2/`) and **`veewash_1099_packet 2/`** in Downloads. The contractor **C-101…C-106** Word templates match the nested `veewash_1099_packet/` copy inside the archive (same filenames).

Use it to ensure **data model + print pipeline** cover every label you pre-fill, and to separate **official government PDFs** (fill as-is) from **internal DOCX/PDF templates** (merge or HTML → PDF).

## 3. VeeWash Employee Information Form (VF-01 style) — semantic fields

Sources: `VeeWash_Employee_Information_Form_Bilingual_v2.docx` and pack section “Employee Information Form”.

- Full legal name; preferred name  
- Home address; city, state, ZIP  
- Mobile phone; alternate phone; email  
- Date of birth  
- SSN or ITIN  
- Emergency contact: name, relationship, phone, alternate phone  
- Work: job title, department/function, start date, supervisor name, primary work location, language preference  
- Worker type: W-2 / temporary / other  
- Laundry experience (Y/N + short text)  
- Essential duties acknowledgment (Y/N)  
- Employee certification text; employee signature; date; received by; date

## 4. Contractor packet C-101 … C-106 (Word) — semantic fields

### C-101 Contractor Intake

- Legal name; business name (optional); mobile; email; home/business address; city, state, ZIP  
- Preferred language (EN/ES)  
- Emergency contact name; phone  
- Service role; start date; primary work location; secondary location  
- Tax/service status: IC vs agency/temp vs other; agency name; agency contact  
- Essential duties acknowledgment (Y/N); reasonable accommodation notice  
- Contractor certification; signature; date; received by; date  
- Internal: contractor ID; entered by; date entered  

### C-102 Independent Contractor Service Agreement

- Effective date; contractor legal name  
- Company notice email placeholder; contractor address (Section 13)  
- Schedule A: contractor name, service role, primary location, service start date, compensation basis (per lb/route/order/other), approved rate reference, payment cycle, tools/app list  
- Schedule B: process steps, quality, productivity/benchmark, gaming data, incentives, adjustment rules, non-compliance consequences  
- Signatures: contractor; company (named MD)  

### C-103 Weekly Contractor Payment Statement

- Contractor name; service week ending; business name; payment date; service role; primary location  
- Line items: description, quantity, rate, hours (reference), amount (many rows)  
- Gross; adjustments; net; payment method/reference  
- Acknowledgment; contractor signature; date; approved by; date  

### C-104 / C-105 / C-106 (notices)

- Contractor name; date of notice; service role; service period/order range; primary location; issued by; prior notice ref  
- C-104: observed issue; standard; corrective action; deadline; immediate effect  
- C-105: prior notice; cure steps; deadline; consequence; company comments  
- C-106: suspension vs cancellation; effective date; reason; property return; final payment notes  
- Acknowledgment; contractor signature; date; issued by; date

## 6. Gap analysis vs current DB (`employee_profiles`)

Already aligned (partial): `first_name`, `last_name`, `employment_type`, address lines, city, state, `zip_code`, `tax_id_type` / `tax_id_value`, pay rates.

**Likely new or extended storage** for full packet parity:

| Domain | Examples |
|--------|----------|
| Identity | Preferred name; DOB; email; phones (mobile, alternate) |
| Emergency | One or two contacts: name, relationship, phones |
| Job | Department; supervisor; primary location; job title; start date; language preference |
| Classification flags | W-2 vs 1099 vs temp; “essential duties” ack; experience text |
| Withholding | W-4 / IT-2104 snapshot JSON per tax year + signed PDF artifact |
| Work authorization | I-9: store **metadata + document types/expiry**, not necessarily raw images in DB (use secure file store) |
| Contractor | Business name; agency linkage; rate basis; schedules A/B text; payment statement lines |
| HR workflow | Form instance id, template version, signed PDF path, signed_at, issued_by user |

Treat **SSN/ITIN/EIN** and **I-9 documents** as **highly sensitive**: encrypt at rest, audit access, minimize retention.

## 7. Recommended implementation order

1. **Canonical person + org profile API** (single source for name, address, FEIN, work locations).  
2. **Official PDF fill** for W-9, W-4, IT-2104, LS-xx, I-9 (field maps per file version).  
3. **DOCX merge** (e.g. python-docx-template) or **HTML templates** for C-1xx and VF/VC internal forms.  
4. **Artifact storage** per employee/contractor: filled PDF path, hash, template version.  
5. UI: **Print / Download** from HR module; optional e-sign later.
